About   
==========================

Denna portfölj är konstruerad med hjälp av HTML, CSS och JavaScript. Jag har använt npm för att hantera beroenden och paket såsom normalize och använt Css för att uppnå en enhetlig stil. Hemsidan är designad med modern CSS, vilket gör att layouten anpassar sig smidigt för att fungera på både dator och mobiltelefon.
